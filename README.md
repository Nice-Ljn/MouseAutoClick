# Mouse Recorder WPF - 鼠标录制工具

一个基于 WPF 开发的功能强大的鼠标操作录制和回放工具，支持脚本管理、多目标点击器和灵活的回放配置。

## 功能特性

### 鼠标录制与回放
- 🎯 **智能录制**: 自动捕获鼠标点击和移动操作
- ▶️ **灵活回放**: 支持自定义重复次数和播放速度
- ⚡ **速度调节**: 0.1x ~ 100x 倍速回放
- 🔄 **无限循环**: 设置循环次数为 0 即无限循环直到手动停止
- ⏱️ **循环间隙**: 可配置每次循环之间的等待时间

### 脚本管理
- 📝 **脚本保存**: 录制完成后自动保存为独立脚本
- 📂 **本地持久化**: 自动保存到用户本地，下次打开自动加载
- 🔤 **重命名**: 双击脚本项或点击重命名按钮自定义脚本名称
- ❌ **删除**: 支持删除不需要的脚本
- 📤 **导出**: 将脚本导出为 JSON 文件分享或备份
- 📥 **导入**: 从 JSON 文件导入脚本
- 📊 **按时间排序**: 脚本列表自动按创建时间排列

### 多目标连点器
- 🎯 **定点点击**: 添加多个固定目标点按顺序自动点击
- ⚙️ **灵活配置**: 每个目标点可独立设置点击类型和延迟时间
- 🔁 **循环控制**: 支持循环次数和循环间隙配置
- 🔘 **点击类型**: 左键、右键、双击等多种类型
- ⌨️ **快捷操作**: F4添加目标点，F5开始，F6停止

### 用户体验
- 🖥️ **多显示器支持**: 准确识别多显示器环境下的坐标位置
- 🎨 **美化界面**: 现代化 WPF 界面设计，简洁美观
- 📜 **美化滚动条**: 流畅的滚动体验
- ⚡ **响应式布局**: 左右并列布局，信息一目了然
- 💬 **实时状态**: 显示操作数和当前状态

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| F1 | 开始/停止录制 |
| F2 | 开始/停止回放 |
| F3 | 停止所有操作 |

| F6 | 停止执行 (多目标连点器) |

## 使用说明

### 录制操作
1. 启动程序后，在左侧看到脚本列表
2. 按 **F1** 或点击「开始录制」按钮开始录制
3. 执行您想要记录的鼠标操作
4. 再次按 **F1** 或点击「停止录制」按钮停止录制
5. 录制完成后自动创建新脚本，无需手动保存

### 回放操作
1. 在脚本列表中选择要回放的脚本
2. 设置「重复次数」（0 = 无限循环）
3. 设置「速度倍率」（0.1 ~ 100 倍）
4. 按 **F2** 或点击「开始回放」按钮开始回放
5. 按 **F2** 或 **F3** 停止回放

### 多目标连点器
1. 切换到「多目标连点器」标签页
2. 按 **F4** 添加当前鼠标位置为目标点
3. 在右侧表格中编辑每个目标点的「点击类型」和「延迟时间」
4. 设置循环次数和循环间隙
5. 按 **F5** 开始执行，**F6** 停止执行

### 脚本管理
- **重命名**: 双击脚本名称或选中脚本后点击「重命名」按钮
- **删除**: 选中脚本后点击「删除」按钮
- **导出**: 选中脚本后点击「导出」，选择保存位置
- **导入**: 点击「导入」，选择 JSON 文件

## 安装与运行

### 环境要求
- Windows 10/11
- .NET 8.0 Runtime

### 编译与运行
```bash
# 克隆或下载项目源码
cd MouseRecorderWpf

# 还原依赖
dotnet restore

# 编译
dotnet build

# 运行
dotnet run
```

### 发布可执行文件
```bash
# 发布为单文件可执行程序
dotnet publish -c Release -r win-x64 --self-contained

# 或者框架依赖发布
dotnet publish -c Release
```

生成的可执行文件位于 `bin/Release/net8.0-windows/win-x64/publish/`

## 常见问题

**Q: 录制的操作在回放时位置不准确？**
A: 确保多显示器配置正确，程序已支持多显示器坐标系统。

**Q: 如何无限循环回放？**
A: 将重复次数设为 0，程序将持续运行直到手动停止。

**Q: 脚本文件可以在其他电脑上使用吗？**
A: 可以！使用「导出」功能将脚本保存为 JSON 文件，在其他电脑上「导入」即可使用。

**Q: 回放速度太快/太慢怎么办？**
A: 调整「速度倍率」，范围从 0.1x（慢动作）到 100x（极速）。

**Q: 多目标连点器中如何编辑目标点？**
A: 直接在表格中修改「点击类型」下拉框和「延迟(ms)」输入框。
